## 記載ルール

- 現行仕様は、画面、Server Actions、Repository、`supabase/migrations`の実装を根拠にする。
- 将来構想や未実装事項は、現行仕様と明確に分けて記載する。
- DB変更時はマイグレーションと本資料を同じ変更で更新する。
- JSONB項目を追加・変更した場合は、キー名、値、入力元を日報仕様またはDB設計へ追記する。
